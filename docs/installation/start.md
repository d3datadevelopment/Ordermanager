# Installation

Diese Seiten unterstützen Sie bei der technischen Einrichtung des Auftragsmanagers. Sie finden hier die passenden Anleitungen für Neuinstallation, Update, Deinstallation und die anschließende Prüfung Ihrer Installation.

Wenn Sie die Einrichtung nicht selbst übernehmen möchten oder besondere Anforderungen Ihrer Hosting-Umgebung berücksichtigen müssen, unterstützen wir Sie gern bei der Installation.

## Vor der Installation prüfen

Prüfen Sie vorab, ob Ihre Shop- und Serverumgebung die Voraussetzungen für das Modul erfüllt:

- [Systemanforderungen](anforderungen/systemanforderungen.md)
- [Kompatibilität](anforderungen/kompatibilitaet.md)

## Passenden Einstieg wählen

Je nach Ausgangssituation führt Sie einer der folgenden Wege zum passenden Ablauf:

- [Neuinstallation](neuinstallation.md)
  Wenn Sie das Modul zum ersten Mal in Ihrem Shop einrichten möchten.
- [Update](update.md)
  Wenn der Auftragsmanager bereits per Composer installiert ist und auf eine neue Version aktualisiert werden soll.
- [Deinstallation](deinstallation.md)
  Wenn Sie das Modul vollständig oder rückstandsfrei aus Ihrer Installation entfernen möchten.
- [Installationsprüfung](installationspruefung.md)
  Wenn Sie nach der Einrichtung kontrollieren möchten, ob das Modul korrekt eingebunden wurde.

## Installation durch D3

Wenn Sie die Installation nicht selbst durchführen möchten, übernehmen wir das gern für Sie oder unterstützen Sie 
bei speziellen Provider- und Umgebungsanforderungen.

Die Kontaktdaten finden Sie unter [Hilfe und Support](../support/hilfe_und_support.md).
