# Systemanforderungen

| Kategorie               | Anforderungen / Details                                                                                  |
|-------------------------|----------------------------------------------------------------------------------------------------------|
| PHP-Version             | 8.x                                                                                                      |
| PHP Decoder             | installierter SourceGuardian Loader                                                                      |
| Shopeditionen           | OXID eShop Community Edition (CE)<br>Professional Edition (PE)<br>Enterprise Edition (EE)<br>B2B Edition |
| Shopversionen           | OXID eShop Compilation Version:<br>7.0.x<br>7.1.x<br>7.2.x<br>7.3.x<br>7.4.x<br>7.5.x                    |
| Templaterender + Themes | Twig: Admin                                                                                              |
| D3 Modul-Connector      | Kostenfrei bei D3 erhältlich<br>ab Version 7.0.0.0                                                       |
| Installation            | Installation via [Composer](https://getcomposer.org)                                                     |
| Sonstiges               | mindestens ein freier Cronjob zur automatischen Ausführung der angelegten Aufgaben                       |

Beachten Sie, dass die Ihnen vorliegende Modulversion entsprechend für Ihre genutzte PHP-Version sowie dem auf Ihrem Server vorhandenen Decoder kompatibel ist. Im Zweifelsfall kontaktieren Sie uns und nennen den für Ihren Shop genutzten Decoder und die PHP-Version.

Kontrollieren Sie bitte auch, ob diese Modulversion für die von Ihnen eingesetzte Shopedition ausgelegt ist.
