# Handbuch

Im Handbuch geht es um die praktische Arbeit mit dem Auftragsmanager im laufenden Betrieb.

Sie richten hier Aufgaben ein, kombinieren Auslöser, Bedingungen und Aktionen und legen fest, ob diese manuell, per Cronjob oder direkt im Bestellablauf ausgeführt werden sollen.

Bevor Sie das Modul nutzen, führen Sie bitte die [Installation](../../installation/start.md) durch.

Die Einstellungen des Moduls finden Sie im Adminbereich Ihres OXID-Shops unter [ (D3) Module ] -> [ Auftragsmanager ].

## Womit möchten Sie starten?

- [Beispielaufgaben](beispielaufgaben.md)
  Wenn Sie zuerst typische Einsatzmöglichkeiten kennenlernen und sich Anregungen für eigene Aufgaben holen möchten.
- [Einstellungen](../bedienoberflaeche/einstellungen/grundeinstellungen.md)
  Wenn Sie die allgemeinen Voreinstellungen des Moduls und die Cronjob-Konfiguration aufrufen möchten.
- [Aufgaben](../bedienoberflaeche/aufgaben/inhalte.md)
  Wenn Sie den Aufbau einer Aufgabe verstehen und bestehende Aufgaben gezielt konfigurieren möchten.
- [Aufgaben automatisch ausführen](../ausfuehrung_mit_cronjob/aufgaben_automatisch_ausfuehren.md)
  Wenn Aufgaben regelmäßig per Cronjob verarbeitet werden sollen.
- [Aufgaben für einzelne Bestellung manuell ausführen](../alternative_ausfuehrungswege/aufgaben_fuer_einzelne_bestellung_manuell_ausfuehren.md)
  Wenn Sie Aufgaben gezielt für eine bestimmte Bestellung starten möchten.
