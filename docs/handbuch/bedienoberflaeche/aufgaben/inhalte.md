# Aufgaben

!!! info "Pfad im Adminbereich"
    [ (D3) Module ] -> [ Auftragsmanager ] -> [ Aufgaben ]

Im Aufgabenbereich legen Sie fest, was der Auftragsmanager mit passenden Bestellungen tun soll und unter welchen Voraussetzungen dies geschieht.

Jede Aufgabe besteht aus mehreren Bausteinen:

- Im Bereich [Stamm](stamm.md) vergeben Sie Namen, Reihenfolge und grundlegende Ausführungseinstellungen.
- Unter [Auslöser](ausloeser.md) legen Sie fest, wann eine Aufgabe gestartet werden darf oder soll.
- In den [Bedingungen](bedingungen.md) bestimmen Sie, welche Bestellungen von der Aufgabe erfasst werden.
- Über die [Aktionen](aktionen.md) definieren Sie, was mit den gefundenen Bestellungen geschieht.
- In der [Übersicht](uebersicht.md) prüfen Sie Bearbeitungsstand, Bedingungen und Aktionen einer Aufgabe.
- Im Bereich [Mall](mall.md) weisen Sie Aufgaben bei Bedarf weiteren Shopmandanten zu.

## Typischer Ablauf

Wenn Sie eine neue Aufgabe anlegen, gehen Sie in der Regel in dieser Reihenfolge vor:

1. Erfassen Sie die grundlegenden Einstellungen im Bereich [Stamm](stamm.md).
2. Wählen Sie passende [Auslöser](ausloeser.md) für die Ausführung.
3. Grenzen Sie die betroffenen Bestellungen über [Bedingungen](bedingungen.md) ein.
4. Definieren Sie die gewünschten [Aktionen](aktionen.md).
5. Kontrollieren Sie die Konfiguration in der [Übersicht](uebersicht.md).
